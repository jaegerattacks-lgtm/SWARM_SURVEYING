# SWARM SURVEYING

A modular robotics project for swarm-based surveying, combining robot bring-up, pose handling, mobile app integration, mechanical design, and supporting documentation in one repository.

## Overview

**SWARM SURVEYING** is a project archive for a surveying robot swarm workflow.  
This repository collects the main software packages, mobile app assets, hardware-related files, drawings, and technical appendices used across the project.

The goal of the project is to support a swarm surveying pipeline where robot motion, pose data, and system integration are handled through a coordinated software-and-hardware setup.

## What’s in this repository

- **Appendices** – technical background, design notes, and supporting documentation
- **Robot demo assets** – media showing robot movement and system behavior
- **ARKitRobotApp** – mobile app package for AR/pose-based interaction
- **PoseReceiver** – pose receiving component for system communication
- **Swarm bring-up** – bring-up package for launching or integrating the swarm system
- **Actuator sizing** – sizing and selection material for actuation
- **Parts** – parts list and component references
- **All drawings** – consolidated mechanical or system drawings
